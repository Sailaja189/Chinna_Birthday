CHINNA REDDY BABU - MULTI-PAGE BIRTHDAY WEBSITE

PAGES
- index.html: Home / birthday welcome
- wishes.html: Personal wishes in English and Telugu
- memories.html: Photo gallery
- videos.html: Video memories page (3 video slots)
- surprise.html: Surprise button and special message

EDITING
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Edit the HTML text to change names, wishes and headings.
4. Edit style.css to change colors, fonts, spacing and design.
5. Edit script.js to change the surprise animation.
6. Open index.html in a browser, or use VS Code Live Server.

ADDING PHOTOS
- Put your photos in the assets folder.
- Gallery filenames: photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg.
- Surprise photo filename: surprise.jpg.
- If your images use different names or formats, update the src values in memories.html and surprise.html.
- Photos must be included in the assets folder before you upload the site, so visitors can see them too.

GITHUB PAGES
1. Create a new public GitHub repository, e.g. chinna-reddy-babu-birthday.
2. Upload all files and the assets folder (keep the same folder structure).
3. Go to Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for the published website link to appear.

TIP: Keep all four HTML pages, style.css, script.js and the assets folder together.

VIDEO MEMORIES
- Put MP4 videos in the videos folder as video1.mp4, video2.mp4 and video3.mp4.
- Open videos.html to edit video titles, Telugu captions and filenames.
- The starter ZIP includes video slots, not personal video files. Add your own clips.
- For smooth playback on phones, use MP4 (H.264 video + AAC audio) and keep file sizes modest.


BACKGROUND MUSIC (ADDED)
- A gentle original birthday instrumental is included at music/birthday-theme.wav.
- A floating "Play birthday music" button is available on all five pages.
- Browsers block autoplay until a visitor interacts with the page, so tap the button to start.
- The button changes to "Pause music" while the music is playing.
- To use your own song later, replace music/birthday-theme.wav with your audio file and update the <source> filename/type in the audio element on each HTML page.
- All original page layouts, wording, photos, videos and styling have been retained; only the music control and its supporting files/styles were added.
